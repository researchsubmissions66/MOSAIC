The Key Idea

Do independently trained pathology foundation models learn the same thing?

Central Hypothesis: Independently trained pathology foundation models learn different coordinate systems over a shared underlying morphological manifold.

If that holds, representations should be alignable, semantic neighbourhoods should survive alignment, features should transfer between models, and a downstream classifier should be able to live inside one shared space.

Method
Benchmark 18 state-of-the-art vision and vision-language pathology encoders across 4,331 TCGA and CPTAC whole-slide images, evaluating similarity, representation alignment, and downstream transferability.
RQ1 · Similarity

How similar are the representation spaces of 18 pathology encoders measured by 7 similarity metrics?

RQ2 · Architecture vs Objective

Does the pretraining objective (Vision SSL vs Vision–Language) drive latent geometry more than architecture?

RQ3 · Alignment

Can the evaluated alignment methods align several models into one shared latent space?

RQ4 · Downstream Impact

Does the aligned space improve downstream MIL classification on 13 morphological, clinical, and molecular tasks?

RQ5 · Cross-model Transfer

Does a classifier trained on one encoder generalise to another encoder's features through the shared space?

Theory & Methods

An overview of the 7 similarity metrics and 5 alignment methods used to compare and align cross-encoder representations.

7 Similarity Metrics

Name What it measures
Linear CKA Linear correlation between representation spaces independent of orthogonal transformations.
Kernel CKA Non-linear correlation capturing higher-order interactions using RBF kernels.
SVCCA Singular Value Canonical Correlation Analysis (PCA followed by CCA).
PWCCA Projection Weighted CCA (weights CCA directions by variance explained).
Procrustes Distance after optimal orthogonal alignment.
Cosine RSA Representational Similarity Analysis using Cosine distance between samples.
Distance Correlation Dependence measure robust to non-linear associations.

5 Alignment Methods

Name What it aligns
GCCA Generalized Canonical Correlation Analysis aligns multiple spaces to a shared latent representation.
MCCA Multi-set CCA extends standard CCA to maximize pairwise correlations among multiple representation sets.
Generalized Procrustes Finds optimal orthogonal transformations to align multiple spaces to a central mean representation.
Joint PCA (jPCA) Computes a shared low-rank subspace across concatenated features.
Shared Autoencoder Learns non-linear mappings into a shared bottleneck capable of reconstructing all modalities.
